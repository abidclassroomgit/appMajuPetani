# PetaniMaju MVP Demo

Demo website untuk aplikasi PetaniMaju - Solusi Cerdas Pertanian

## 🚀 Quick Start

### Frontend
```bash
cd frontend
npm run dev
```
Buka: http://localhost:3000

### Backend (Optional)
```bash
cd backend
npm run dev
```
API: http://localhost:3001

## 📱 Fitur

- **Dashboard**: Prakiraan cuaca 7 hari + tips harian
- **Perpustakaan Tips**: Cari dan filter tips pertanian
- **Profil**: Informasi petani dan pengaturan

## 🛠️ Tech Stack

- **Frontend**: Next.js 16, Tailwind CSS, TypeScript
- **Backend**: Express.js, Node.js
- **Database**: PostgreSQL (ready), Prisma ORM
- **PWA**: Offline support dengan IndexedDB
